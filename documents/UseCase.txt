#TaskTracker add task Use Case V1.0
1. user open the CLI
2. user enter first command to add a task
3. application ask user for enter some info.:
	3.1 enter name: A name of the task(task name)
	3.2 enter description: A short description of the task
	3.3 enter status: The status of the task (todo, in-progress, done)
4.appication set ID and createdAt(The date and time when the task was created) for task
5.application parse information at 3 step in JSON format
6.appication write JSON data in a .json file
7.json file save in current directory
8.application display message: Task added successfully (ID: ?)
## we should find name and verb in the use case:
	name:user-CLI-command-task-id-description-status-createdAt-information-JSON data-file-current directory-message
	verb:open-enter-add-ask-set-parse-write-save-display

#TaskTracker Use Case V2.0: update task
1. user open the cli application
2. user enter command to update a task
3. application ask user for enter ID of task
4. user enter ID
5. application ask user for info. that wants update
	5.1 enter id: A unique identifier for the task(task name)
	5.2 enter description: A short description of the task
	5.3 enter status: The status of the task (todo, in-progress, done)
8.appication set updatedAt(The date and time when the task was updated) for task
9.application update info. and write in a file
	9.1 if user was entered null(or empty) for any info., application don't update that info.
10.application display message: Task updated successfully (ID: ?)
